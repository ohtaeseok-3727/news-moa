# 뉴스 모아 Rust 1.4

Windows 10/11 64비트 본체에서 AI 제품의 새 기능·모델 출시·API 변경과 게임 소식을 모아 한국어 요약으로 보여주는 프로그램입니다.

## 실행

압축을 풀고 `news_moa.exe` 또는 `실행.bat`을 실행하세요. 같은 PC에서 `http://localhost:8765`를 엽니다. 첫 실행 시 공개 모델 약 2.8GB를 다운로드하고 파일을 검사합니다. 진행 상황은 실행 창과 웹 화면에 표시됩니다. Python, Rust, Ollama의 별도 설치는 필요하지 않습니다. 모델 설치만 먼저 하려면 `모델준비.bat`을 실행하세요.

같은 공유기에 연결된 휴대폰이나 PC에서는 `http://본체IPv4주소:8765`에 접속합니다. 본체의 명령 프롬프트에서 `ipconfig`로 IPv4 주소를 확인합니다. 브라우저에서 아이디 `news`와 프로그램 폴더의 `access-key.txt`에 자동 생성된 암호를 입력하세요. `--data-dir`을 지정하면 해당 폴더에 암호가 있습니다. 기존 파일과 함께 보관하세요. Windows 방화벽은 사설 네트워크에서만 접근을 허용하세요. 연결은 HTTP이므로 암호가 네트워크에서 암호화되지 않습니다. 신뢰하는 집 안에서만 사용하고 공유기 포트 포워딩을 켜지 마세요.

## 처리 방식

- AI 목록은 최근 14일의 새 모델·기능 출시, API·개발 도구 변경을 제목과 출처 기준으로 선별합니다. 기업의 AI 도입·활용 사례, 투자·정책·교육·사용 후기 등은 제외합니다. 정확한 업데이트만 남기는 쪽으로 설정해 제목이 모호하면 실제 새 기능 기사도 빠질 수 있습니다.
- `AI 제외 항목 검토`에서 최근 수집된 제외 항목을 확인할 수 있습니다. 해당 목록은 사용 사례 등도 포함할 수 있으며 자동 요약하지 않습니다. AI 공식 발표 검색을 추가했습니다.
- 화면에 버전, 업데이트 확인 상태, 요약 대기·실패 건수와 수집 출처별 성공·실패 및 요약 실패 원문 도메인을 표시합니다.
- 기사 본문은 DNS 확인, 주소 고정 및 이동 주소 재검사를 통해 사설 IP나 로컬 주소 연결을 차단합니다. 일반 HTTP(S) 80/443 포트만 허용합니다.
- 기존에 저장된 AI 적용 사례나 오래된 기사는 목록과 요약 대기열에서 숨깁니다. 데이터베이스의 원본 기록은 삭제하지 않습니다. 게임 수집 범위는 유지합니다.

- 실행 직후와 약 1시간마다 Google 뉴스 검색 RSS, Google AI 블로그, OpenAI 뉴스, PC Gamer 및 Hacker News를 수집합니다. RSS는 출처별 최신 50개까지 수집하며 화면에는 최근 500개를 표시합니다.
- Hacker News는 인기 글 상위 100개 중 제목의 AI·게임 키워드를 기준으로 가져오며 추천·댓글 수는 수집 시점 값입니다. 댓글 전체를 요약하거나 커뮤니티 전체의 여론을 분석하지 않습니다.
- 공개 원문에서 본문을 추출한 뒤 **mT5 XL-Sum으로 원문 언어 요약 → 영어일 경우 OPUS-MT로 요약만 한국어 번역**합니다. 한국어 본문은 번역을 건너뜁니다. 현재 한국어와 영어를 지원합니다.
- 전체 본문 번역은 생성하지 않습니다. 최대 5,760토큰까지 여러 부분으로 나눠 요약하며, 제한을 넘으면 요약에 표시합니다.
- 원문에 없는 숫자·영문 약어 등이 생성되거나 한국어·영어 문장의 단어 대응이 부족하면 핵심 문장 발췌로 대신하고 표시합니다. 이는 간단한 오류 완화 기능이며 완전한 사실 검증을 보장하지 않습니다.
- 모델은 CPU에서 차례대로 실행합니다. 기사 길이와 PC 성능에 따라 처리 시간이 달라집니다. 모델 준비 완료 후 기사 내용을 외부 AI 서비스에 전송하지 않습니다.
- Google 뉴스 중간 주소는 실제 언론사 주소로 연결한 뒤 저장합니다. 이후 재시도에는 저장한 원문 주소를 사용하며, 화면의 제목도 해당 주소로 연결됩니다. 이 공개 연결 방식은 Google 페이지나 응답 형식이 바뀌면 실패할 수 있습니다.
- 한국어 사이트의 문단·줄바꿈 본문, EUC-KR/CP949 인코딩, 공개 JSON 기사 데이터를 지원합니다. 로그인·유료 기사, 자동 접근 제한 및 일부 페이지 구조에서는 본문 요약을 만들 수 없습니다. 실패 이유가 표시되며 재시도할 수 있습니다.

모델 다운로드가 끊기면 자동 재시도합니다. `models` 폴더를 보존하면 이후 다시 다운로드하지 않습니다. 원본 파일의 크기와 주요 파일의 SHA-256을 확인합니다. 프로그램은 모델 로드와 뉴스 수집을 위해 디스크 공간과 충분한 RAM이 필요하며, 64비트 Windows용 CPU 빌드입니다. GPU 가속은 이 배포본에 포함하지 않았습니다. 모델과 실행 중 임시 작업을 고려해 적어도 6GB 이상의 여유 디스크 공간을 확보하세요.

## 데이터와 이전

1.3부터 프로그램 시작 시와 실행 중 6시간마다 GitHub의 `ohtaeseok-3727/news-moa` 공개 릴리스를 확인합니다. 더 높은 정식 버전의 `news_moa.exe`를 내려받아 GitHub가 제공한 SHA-256 및 파일 크기를 확인한 뒤 자동으로 교체하고 재시작합니다. 잠시 웹 접속이 중단되며 진행 중인 요약은 다시 처리될 수 있습니다. 1.4 이후 업데이트부터 새 서버의 시작을 확인하고 60초 이내에 실패하면 기존 실행 파일을 복구합니다. 이 검사는 서버가 포트를 열었는지 확인하며 이후의 모든 오류를 감지하지는 못합니다. 1.3에서 1.4로 업데이트할 때는 1.3의 이전 교체 방식이 사용됩니다. 해시는 다운로드 오류 검사용이며 GitHub 계정이 침해된 경우 악성 릴리스를 막아주지는 않습니다. 저장소 계정 보안이 중요합니다.

1.2 업데이트: 실행 중인 프로그램을 종료하고 새 `news_moa.exe`만 기존 폴더에 덮어쓰세요. `models`와 `news.db`를 유지하면 모델 재다운로드 없이 기존 기사를 새 AI 선별 기준으로 다시 분류합니다.

1.0에서 업데이트할 때는 실행 중인 프로그램을 종료하고 새 `news_moa.exe`만 기존 폴더에 덮어쓰세요. `models` 폴더와 `news.db`는 그대로 보존합니다. 이전 버전의 Google 중간 링크 오류로 실패했던 기사는 1.1 실행 시 자동으로 다시 처리합니다. 모델 파일은 바뀌지 않아 다시 내려받을 필요가 없습니다.

프로그램과 같은 폴더의 `news.db`에 기사가 저장됩니다. 이전 버전에서 옮길 때는 프로그램을 종료하고 데이터베이스를 백업한 뒤 새 실행 파일 옆에 복사하세요. 기존 기사는 유지되고 Rust 요약 방식으로 다시 처리됩니다. 예전 전체 번역 데이터는 데이터베이스에 남아 있지만 새 웹 화면에는 표시되지 않습니다.

창을 닫거나 본체를 끄면 수집과 웹 접속이 중단됩니다. Windows 절전 중에도 수집하지 않습니다. `실패 재시도`는 본문 추출·요약에 실패한 글을 다시 대기열에 넣습니다.

## 모델 출처 및 이용 조건

- 요약: BUET CSE NLP Group, [mT5_multilingual_XLSum](https://huggingface.co/csebuetnlp/mT5_multilingual_XLSum), CC BY-NC-SA 4.0. 원본 모델의 자동 Safetensors 변환 브랜치의 고정 리비전을 사용합니다.
- 요약 토크나이저: [lmz/mt5-tokenizers](https://huggingface.co/lmz/mt5-tokenizers), mT5 토크나이저 변환본.
- 번역: Helsinki-NLP, [opus-mt-tc-big-en-ko](https://huggingface.co/Helsinki-NLP/opus-mt-tc-big-en-ko), CC BY 4.0. 영어 입력은 source.spm의 원래 토큰 순서를 유지하도록 구현했습니다.
- 추론: Hugging Face Candle. Marian 토크나이저 변환 코드는 Candle 예제를 수정해 사용하며 해당 라이선스를 함께 제공합니다.

이 구성은 개인의 비상업적 사용을 위한 것입니다. 상업적 사용으로 바꾸기 전에는 특히 요약 모델의 비상업적 이용 조건을 검토해야 합니다. AI 결과는 잘못되거나 원문에 없는 내용을 포함할 수 있어 원문 확인이 필요합니다.

## 개발

소스 패키지에서 MSVC Rust 툴체인과 Visual Studio C++ 빌드 도구를 설치한 후 `cargo build --release --locked`를 실행합니다. 배포용 빌드는 `.cargo/config.toml`의 정적 CRT 설정을 사용합니다. 사용자 PC에는 이 빌드 도구가 필요하지 않습니다.

추가 옵션: `--prepare`(모델 준비), `--data-dir <폴더>`(데이터 폴더), `--summarize-file <UTF-8 파일>`(요약 시험), `--check-url <주소>`(본문 추출 검사), `--summarize-url <주소>`(기사 요약 시험), `--version`(버전 확인).

검사: `cargo test --release --locked`. 모델이 준비된 상태에서는 `news_moa.exe --prepare --data-dir test-data` 실행 후 `cargo test --release --locked -- --include-ignored`로 번역 및 입력 토큰 회귀 검사까지 실행할 수 있습니다.
